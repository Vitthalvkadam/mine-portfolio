Drop REAL, licensed, human-recorded audio here. Files are detected at build time
(nothing is played or referenced unless the file exists). Formats: mp3 / ogg / wav / m4a.

  splash.*       short cinematic intro sting / voice for the splash screen (2-4s)
  scream.*       human-recorded horror scream / impact for the ghost attack (1-3s)
  certificate.*  short human voice line for certificate clicks (e.g. "Kya yaar, you don't believe my words?")

Restart `npm run dev` after adding files.
