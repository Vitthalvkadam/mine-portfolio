Ghost images for Crazy Mode (optional local copies; auto-detected at build time):
  ghost-primary.jpg|png|webp|avif    main full-screen attack ghost
  ghost-secondary.jpg|png|webp|avif  ghost that runs behind the page
If missing (or failing to load) the two image URLs supplied by the owner are tried,
then a built-in SVG face. Restart `npm run dev` after adding files.
